# organisms/

Componentes con dominio: los que sí saben qué es un perfil o una entrevista, a diferencia de
`design-system/` (`docs/ARCHITECTURE.md` §1, §3). Se arman combinando átomos y moléculas del
design system.

Ejemplo planeado (`docs/ARCHITECTURE.md` §3, líneas 171-172; HE-04, Sprint 1): los 5 organismos
que ARCHITECTURE.md planea para este paso — `OfferAndRoleStep`, `ModeAndToneStep`,
`LanguageAndFormatStep`, `SetupSummary`, `NoProfileGate` — en `interview-setup`. Ninguno existe
todavía en disco. Verificado contra `interview-setup` con `find` el 11-sep-2026.

Se llenan en el paso 3 del orden de construcción de `CLAUDE.md` §8, contra datos simulados,
junto con los **hooks de interfaz** que necesiten (ver `hooks/README.md`).
